# OpenWaitlist

Microservicio FastAPI para gestión de waitlists y leads. Recibe registros de formularios de landing pages y los organiza en listas nombradas, con panel admin opcional.

## Stack

- **Backend**: Python 3.12+, FastAPI, SQLAlchemy 2.0 (async), Alembic
- **Panel admin**: React + TypeScript (opcional, en `admin-panel/`)
- **Base de datos**: SQLite (dev) / PostgreSQL (producción)
- **Infra**: Docker Compose
